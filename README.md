# Data Analyst Telegram Bot (TDS P1 T2)

This repository contains the Telegram Data Analyst Bot for TDS Project 1 Task 2 evaluation.

## Files
- `bot.py`: Main Telegram bot script.
- `requirements.txt`: Python dependencies (`python-telegram-bot`, `python-dotenv`).
- `run.jsonl`: Local interaction log file.

## Setup & Execution
```bash
pip install -r requirements.txt
python bot.py
```
